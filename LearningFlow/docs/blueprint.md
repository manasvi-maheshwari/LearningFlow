# **App Name**: LearnFlow

## Core Features:

- Course Information Display: Display basic course information such as title, description, schedule, and instructor.
- User Authentication: Allow admins, students, and faculty to log in and authenticate using a secure system.
- CGPA Calculator: Provide a CGPA calculator for students to estimate their grade point average. The calculations must be based on predefined assessment rules.
- Attendance Portal: Enable faculty to record student attendance via an interactive portal.
- Resource Recommendation: AI-powered tool to recommend relevant learning resources based on student's enrolled courses and academic performance.

## Style Guidelines:

- Primary color: Slate Blue (#6A5ACD) for a modern and intellectual feel.
- Background color: Light Gray (#F0F0F0) providing a clean, distraction-free backdrop.
- Accent color: Soft Lavender (#E6E6FA) to highlight key interactive elements.
- Body text: 'Inter', a grotesque-style sans-serif, should be used here because of its modern look.
- Headline text: 'Space Grotesk', sans-serif. 'Inter' can be used for the body.
- Use modern and clear icons to represent different course modules and functionalities.
- The layout of the progress dashboard is clean and structured, providing clear insights into academic performance.
